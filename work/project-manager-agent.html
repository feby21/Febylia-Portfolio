The problem

Lectures, a part-time job and several projects all compete for the same week. Planning that by hand takes time, and the project that slips is usually the one without a deadline shouting at me.

I wanted one place that holds every project, ranks what deserves my time, plans the work into my calendar and tells me each morning what to do next. It also had to leave my fixed commitments alone unless I say otherwise.

The fintech bit

The Priority Score

Every project gets a score from 20 to 100, built like a weighted index. Five factors are each rated 1 to 5, then weighted. The agent calculates it from the raw data every time and names the factors that drove a ranking.

Score = round((Urgency × 0.30 + Importance × 0.25 + Strategic value × 0.20 + Progress risk × 0.15 + Neglect × 0.10) × 20)

Design principles

  1. Clarity over complexity. No admin overhead.
  2. Action over information. Tell me what to do next.
  3. Realistic planning. It respects lectures, shifts and rest.
  4. Human approval over automation. The agent writes only to its own calendar, and only after I approve. It never touches my fixed commitments.
  5. One source of truth. The rules live in one Notion manual that every chat and scheduled task reads.

What I learned

  • Work around what the tools can't do. The Notion connector can't read formula results, so the agent calculates the score itself from a rules page that mirrors the formula.
  • Limit what an agent can write to. Giving it one calendar of its own made it safe to let it plan freely.
  • Keep the rules in one place. Once every chat and scheduled task read the same manual, the behaviour became consistent.
